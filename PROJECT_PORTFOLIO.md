## Research Replication Portfolio

---

# Executive Summary

This repository presents a comprehensive replication and engineering implementation of the research paper:

> **A Cost-Effective Sequential Route Recommender System for Taxi Drivers**

The objective of this project was not only to reproduce the published methodology but also to transform an academic implementation into a professional, reproducible, and maintainable software project using modern software engineering practices.

The project combines machine learning, graph neural networks, sequential modelling, software architecture, testing, DevOps, and technical documentation into a single production-quality repository.

---

# Project Motivation

Many research repositories demonstrate promising algorithms but lack:

- reproducibility
- documentation
- maintainability
- automated testing
- deployment support
- software engineering standards

The goal of this project was to bridge the gap between academic research and production-quality software engineering.

# Challenges Encountered

Several technical challenges were encountered during development.

## TensorFlow Compatibility

The original repository relied on TensorFlow 1.x APIs.

To reproduce the project successfully, the development environment had to be adapted to Python 3.10 with compatible TensorFlow versions.

---

## Dependency Management

Several package versions were incompatible with modern Python releases.

A dedicated virtual environment and dependency management strategy were established to ensure reproducibility.

---

## Repository Modernization

The original research code focused primarily on algorithm implementation.

The repository was restructured into a modular architecture with clear separation between:

- source code
- scripts
- documentation
- tests
- configuration

---

## Documentation

A significant effort was devoted to documenting every stage of the project, enabling future users to reproduce and extend the work.
