# [1.0.0] - 2026-07-21

## 🎉 Initial Public Release

This release represents the first complete version of the **Taxi Route Recommender** repository.

The project successfully reproduces the Graph Convolutional Network (GCN) and Long Short-Term Memory (LSTM) based taxi route recommendation system described in the research paper **"A Cost-Effective Sequential Route Recommender System for Taxi Drivers"**, while extending it with professional software engineering practices, automation frameworks, and comprehensive documentation.
