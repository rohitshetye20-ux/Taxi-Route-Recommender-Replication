# Overview

We are pleased to announce the first public release (v1.0.0) of the **Taxi Route Recommender System**.

This repository presents a structured replication and engineering implementation of the research paper:

> **A Cost-Effective Sequential Route Recommender System for Taxi Drivers**

The project demonstrates reproducible machine learning workflows, software engineering best practices, comprehensive documentation, automated testing, and modern DevOps practices.

# Known Limitations

Current limitations include:

- TensorFlow version compatibility depends on the selected Python environment.
- Large datasets are not bundled with the repository.
- GPU acceleration requires additional CUDA configuration.
- Hyperparameter optimization is not automated in this release.
